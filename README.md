## 🌟 Tentang Project

**CV Builder Web App** adalah aplikasi web interaktif yang memudahkan pencari kerja membuat curriculum vitae (CV) profesional, estetis, dan **ATS-Friendly** dalam hitungan menit. Ditenagai oleh **Streamlit**, **Jinja2 Templating**, dan HTML-to-PDF Converter, Anda dapat langsung mengunduh hasil CV beresolusi tinggi tanpa perlu keahlian desain.

---

## 🚀 Fitur Utama

- 🎨 **10+ Template CV Premium**: Dari gaya ATS-Friendly bersih hingga desain Executive & Tech Monospace.
- 🔤 **16+ Pilihan Font Family**: Pilihan font populer yang dikelompokkan berdasarkan kategori (*Sans-Serif, Serif, Monospace*).
- 🎨 **Color Picker Dynamic**: Sesuaikan warna aksen CV sesuai dengan kepribadian atau industri impian Anda.
- 👁️ **Live Interactive Preview**: Lihat perubahan CV secara *real-time* sebelum diunduh.
- 📸 **Upload Foto Profil**: Dukungan foto profil otomatis (*Base64 encoded*) dengan tata letak adaptif.
- 📥 **Export to PDF**: Cetak langsung ke format PDF standar ukuran **A4** dengan margin dan layout presisi.
- 🔒 **Privasi Terjaga**: Data Anda diproses secara lokal / *in-memory*, tanpa menyimpan informasi pribadi ke database.
